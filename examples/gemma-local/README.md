# Gemma on a laptop

`explain.txt` is the output of `git mm explain` on the demo backport conflict
(`git mm demo`, then `git cherry-pick -x hotfix-812`) with `gemma4:e4b` served by
Ollama 0.40.13 on a 16 GB MacBook Pro. The call took about 14 seconds. `ollama ps`
at the end shows the model loaded locally.

Gemma's wording and suggestion can differ between runs. The provenance part comes
from git and does not.
